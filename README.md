# dumbo-jump-site

덤보 점프의 **공개 문서 사이트**. 개인정보 처리방침과 지원 페이지를 담는다.

GitHub Pages 로 <https://nekarose.github.io/dumbo-jump-site/> 에 서비스된다.

## 왜 코드와 나눠 두나

스토어 등록정보는 **누구나 열 수 있는 URL** 로 처리방침과 지원 창구를 요구한다.
게임 코드 저장소(`dumbo-jump`)는 비공개라 그 자리에 쓸 수 없다. 그래서 밖으로
나가야 하는 문서만 여기로 갈랐다 — 덤보 드랍이 `app-ads.txt` 를
`nekarose.github.io` 로 갈라 둔 것과 같은 이유다.

## 구조

| 경로 | 쓰이는 곳 |
|---|---|
| `/privacy/` · `/privacy/en/` | App Store·Play 등록정보의 개인정보 처리방침 URL |
| `/support/` · `/support/en/` | App Store 등록정보의 지원 URL |
| `/` | 위 넷으로 가는 문 |

`app-ads.txt` 는 **여기 두면 안 된다.** AdMob 크롤러가 개발자 웹사이트의
도메인만 가져다 루트를 읽으므로 `nekarose.github.io` 에 있어야 한다. 덤보
점프의 게시자 ID(`pub-9055371492725478`)는 덤보 드랍과 같아서 이미 그 파일이
덮고 있다 — 새로 더할 것이 없다.

## 고칠 때

처리방침을 고치면 페이지의 **시행일**도 같이 고친다. 이전 내용은 커밋 기록에
남으므로 따로 보관할 필요가 없다.

앱이 수집하는 것이 바뀌면(분석 도구를 넣거나, 계정을 만들거나, iOS 추적 권한을
요청하게 되면) **처리방침이 먼저 틀린 말이 된다.** 그런 변경은 여기부터 고친다.
